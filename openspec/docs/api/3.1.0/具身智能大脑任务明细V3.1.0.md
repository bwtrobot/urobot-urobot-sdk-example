### 机器人基础信息上报 `robot_info_upload_req`

```json
// true: 开启上报（立即上报一次并持续上报）；false: 关闭上报
"command_param": true
```

开启后，机器人基础信息通过 socket 消息（`messageType=robot_info_upload`）持续上报，上报字段如下：

| 字段 | 类型 | 子字段 | 说明 |
|---|---|---|---|
| `morphology` | string | - | 机器人空间场景形态：`physical` 物理 / `simulation` 仿真 |
| `sim_stream` | string | - | 仿真视频流地址 |
| `version` | string | - | 系统版本 |
| `serial_number` | string | - | 机器 SN 码 |
| `cpu_temperature` | int | - | CPU 温度 |
| `cpu_load` | double | - | CPU 负载 |
| `used_memory` | double | - | 内存占用率 |
| `net_name` | string | - | 网卡名 |
| `net_mac_address` | string | - | 网卡 MAC 地址 |
| `net_ip_address` | string | - | 网卡 IPv4 地址 |
| `up_bw` | double | - | 上行带宽 |
| `down_bw` | double | - | 下行带宽 |
| `level_dbm` | double | - | 网络信号强度 |
| `disk_usage` | int | - | 磁盘用量比例 |
| `soc` | int | - | 电池电量 |
| `current` | int | - | 电流 |
| `voltage` | int | - | 电压 |
| `motion_control` | string | - | 运控模式 |
| `charge` | object | `status(int)`：充电状态（0 空闲 / 1 充电中 / 2 异常）<br>`org_value(int)`：原始值 | 充电信息 |
| `motion_lock` | bool | - | 运动锁定：`true` 锁定 / `false` 未锁定 |
| `robot_state` | object | `status(int)`：0 未知 / 1 可行走站立 / 2 不可行走站立 / 3 正常趴下 / 4 异常趴下<br>`status_desc(string)`：状态描述<br>`org_value(object)`：原始值（x30_basic_value、x30_gait_value、value_desc） | 机器人运控状态 |
| `run_model` | string | - | 当前模式：`chat-only` 对话模式 / `chat-task` 任务模式 |
| `control_status` | string | - | 导航-控制状态 |
| `damp` | int | - | 阻尼：0 零力矩 / 1 阻尼 / 2 位控下蹲 |
| `map_name` | string | - | 当前激活地图名称 |
| `package_path` | string | - | 激活地图包路径/ID |
| `version_path` | string | - | 激活地图版本路径/ID |
| `state` | string | - | 导航-主状态（`/x_nav/master/state`） |
| `nav_state` | string | - | 导航-nav 状态（`/nav/state`） |
| `base_link_height` | string | - | base_link 高度 |
| `slam_state_error` | bool | - | slam 状态异常，连续 -1 为异常 |
| `ros_odom` | object | `pose(object)`：位姿数据 | 实时位姿 |
| `vel` | object | `linear_combined(double)`：合成线速度（m/s）<br>`angular_z(double)`：旋转速度（度/s） | 速度 |
| `obstacle_avoidance_broadcast` | bool | - | 避障播报开关 |
| `ground_map_area` | string | - | 当前激活地图区域面积（平方米） |
| `nav_remaining_distance` | string | - | 导航剩余距离（米），距当前规划路径终点的曲线距离，1Hz 更新 |

### 机器人操作 `robot_operate`

```json
{
    "operate_type": 1,
    // 1: 清空聊天记忆
    // 2: 切换机器人模式
    // 3: 机器人系统升级
    // 4: 仿真机器人重启
    // 5: B2 软急停（趴下，需重启机器狗才能恢复站立）
    // 6: 移动速度控制（修改导航跟踪速度，单位 m/s）
    // 7: G1 运控模式切换
    // 8: 终止 agent 推理
    "operate_param": {
        "conversation_id": "123",    // operate_type=1 清空的聊天记忆 ID 必填；operate_type=8 终止推理的会话 ID
        "run_model": "chat-task",    // 任务 chat-task、聊天 chat-only；operate_type=2 必填
        "version": "v2.6.0",         // 升级版本号；operate_type=3 必填
        "restart_simulation": true,  // 仿真机器人重启；operate_type=4 必填
        // operate_type=5 无需额外参数，传空对象 {} 即可
        "target_velocity": 0.8,      // 导航跟踪速度（m/s）；operate_type=6 必填
        "motion_mode": "lock_stand", // G1 运控模式；operate_type=7 必填
        // 可选值：zero_torque / damp / squat / sit / lock_stand /
        //         balance_squat / lie_stand / normal_ctrl /
        //         normal_ctrl_waist / walk_run_ctrl
        "agent_id": "robot-assistant-001" // 终止推理目标 agentId；operate_type=8 必填
    }
}
```

### 音乐播放控制指令 `play_music`

> 异步任务，机器人执行后通过 `/agent_command_reply` 回执闭环。
>
> - `action=play` 且 `song` 为 URL 链接：播放该链接音乐
> - `action=play` 且 `song` 为歌曲名：播放本地对应音乐
> - `action=stop`：停止播放

**播放链接音乐：**
```json
{
    "action": "play",
    "artist": "",
    "song": "https://example.com/music/song.mp3"
}
```

**播放本地音乐：**
```json
{
    "action": "play",
    "artist": "歌手名",
    "song": "歌曲名"
}
```

**停止播放：**
```json
{
    "action": "stop",
    "artist": "",
    "song": ""
}
```

### AI 生成任务 `ai_generate`

统一入口，按顶层 `type` 字段分流：

- **`t2i`**：文生图，支持百炼/方舟双渠道
  - 百炼默认模型：`qwen-image-2.0-pro`
  - 方舟默认模型：`doubao-seedream-5-0-260128`
- **`t2t`**：生成/优化系统 prompt，`prompt` 字段传"角色设定"

#### t2i 示例（百炼）

```json
{
    "type": "t2i",
    "api_key": "sk-your-api-key-here",
    "prompt": "一只机器人站在未来城市广场，电影感光影，细节丰富"
}
```

#### t2i 示例（火山方舟）

```json
{
    "type": "t2i",
    "api_key": "ark-your-api-key-here",
    "prompt": "讲解机器人"
}
```

#### t2t 示例

```json
{
    "type": "t2t",
    "prompt": "面向5-12岁儿童的科普讲解助手，语气活泼、用类比代替术语，回答控制在3句话内"
}
```

#### result 结构

**t2i 响应：**
```json
{
    "type": "t2i",
    "image": {
        "channel": "aliyun_bailian",
        "request_id": "xxx",
        "model": "qwen-image-2.0-pro",
        "size": "2048*2048",
        "image_count": 3,
        "images": [
            {
                "index": 1,
                "url": "https://dashscope-result-xxx.png?Expires=xxx",
                "image_type": "url"
            }
        ]
    }
}
```

**t2t 响应：**
```json
{
    "type": "t2t",
    "text": "你是一名面向 5-12 岁儿童的科普讲解机器人。语气活泼、亲切，多用类比少用专业术语；每次回答不超过 3 句话；遇到不确定的问题主动说『让我去查一下』。"
}
```
