1.  文档概述

本接口文档(版本V2.9.0)紧密围绕产品规格书定义的"智能管理与操作核心"关键功能，通过标准化API接口将系统的导航建图、路径规划、集群控制、智能交互等核心能力封装为可调用服务，支撑第三方业务系统与机器人本

体的高效集成，实现"降低智能化应用开发门槛、加速创新落地"的产品目标。其功能覆盖接口鉴权、机器人全生命周期管理、地图与路径管理、任务与指令控制、数据交互五大维度，具体如下：
**接口鉴权：保障安全可信的系统访问**

提供获取凭证（/token）与刷新凭证（/refresh）接口，基于 accessKey/secretKey 生成签名（SHA256 加密），输出 accessToken（访问令 牌）与 refreshToken（刷新令牌），用于后续接口调用的身份验证。令牌有效 期可通过 JWT 解析获取，确保接口调用的安全性与合法性。

**机器人管理：全生命周期状态与数据管控**

围绕产品规格书"机器人设备管理""实时监控与告警"能力，提供机器人

列表查询、运行数据监测、任务控制、状态追踪接口：

• 机器人列表（/robot/page）：分页查询机器人基础信息（ID、SN、名

称、状态、类型、电量、关联地图等），支持按名称、状态（离线/空闲

/忙碌）、类型（机器狗/机器人）筛选，对应"设备管理-设备注册/多

设备管理"功能。

• 运行数据（/robot/runtime/{robot}）：实时获取机器人运行指标（电

量、CPU/内存/温度、网络状态、SLAM 状态、充电状态等），更新频次

3s/次，对应"监控与告警-实时状态监测"功能。

• 任务控制（/robot/commnad/{robot}）：向机器人下发任务指令（如导

航、基础运动、地图激活、拓扑导航、语音播报、充电控制等），支持

自定义指令参数（如目标位置、运动方向、地图版本），返回 taskId 用

于状态查询，对应"运动与动作控制""自主导航""智能交互"等功

能。

• 任务状态（/robot/task-result/{robot}）：查询任务执行结果（任务

ID、状态（已发出/执行中/完成/异常）、指令结果集），对应"监控与

告警-实时状态监测"中的任务进度追踪。

**地图与路径管理：三维空间能力的标准化输出**

基于产品规格书"导航地图管理""空间智能融合"能力，提供地图创建、

版本、路径、点位的全生命周期接口：

• 地图基础管理：地图列表（/map/page）分页查询地图（ID、名称、创建

时间、收藏状态）；地图版本列表（/map/{mapId}/editions）查询指定

地图的所有版本（版本 ID、名称、创建时间、全局/地面点云路径、BIM

模型信息），对应"导航地图管理-地图版本管理"。

• 地图版本控制：指定地图版本（/map/edition/{id}）查询单个版本的详

细信息；指定地图版本（/map/edition/list）批量查询多版本信息；地

图版本充电点位（map/edition/{id}/charging-stations）获取版本内

的充电点位置；地图版本导出导航点（map/edition/export/nav

points）导出导航点至文件，对应"导航地图管理-地图管理与下发"。

• 路径与拓扑管理：拓扑路径列表（/map/topo-path/page）分页查询拓扑

路径（UUID、名称、关联地图/版本）；拓扑路径 UUID 查询

（/map/topo-path/{uuid}/edition）查询指定版本中的拓扑路径详情

（节点、边、通行方向）；导航路径列表（/map/nav-path/page）分页

查询导航路径；导航路径 UUID 查询（/map/nav-path/{uuid}/edition）

查询导航路径的节点信息，对应"导航地图管理-路径点编辑与路径规

划""自主导航-多种导航能力"。

**数据交互：实时性与可扩展性的支撑**

• 机器人数据订阅（/robot/set/callback）：配置机器人数据回调地址，

实时推送订阅的 Topic 数据（如速度、点云、导航路径、相机画面

等），对应"监控与告警-监控视频实时回传""空间智能理解-实时感

知"功能。

• 对象模型定义：明确机器人、地图、任务、指令等对象的参数结构（如

机器人对象包含 ID、SN、状态、配置、关联地图；地图版本对象包含版

本 ID、地图 ID、点云路径、BIM 信息），为接口调用提供标准化数据格

式，对应产品规格书"系统架构"中的对象模型设计。

**指令与异常：细粒度控制的底层支撑**

• 机器人指令说明：定义中枢向机器人下发的指令格式（如位姿初始化、

基础运动、导航、拓扑导航、语音播报、充电控制等），包含

command_code（指令类型）、command_param（指令参数）、

parallel_commands（并行指令），对应"运动与动作控制-直接运动控

制/紧急控制""自主导航-自主定位与路径规划"等功能。

• 异常码说明：定义接口返回的错误码（如 0000 成功、9999 系统错

误），确保调用方能快速定位问题，对应产品规格书"安全与稳定性保

障"中的异常处理要求。
